# Estoque-do-Gabriel
Um sistema desenvolvida para ser um gerenciamento/controle de estoque de produtos diversos. Com todas as funcionalidades como: cadastro de produtos, atualização de protudos (adicionar ou retirar), consulta e alerta para produtos abaixo do estoque.

# Funcionalidades
1  Cadastro de produtos

2  Atualização de produtos (Entrada e Saida)

3  Consulta de produtos 

4  Alerta de estoque baixo

# Estrutura 
1 - cadastro_de_produtos: 
Tem a função de fazzer o cadastramento dos produtos, necessariamente com 4 informações: item(nome do produto), categoria, quantidade e preço. 

2 - registrar_entrada: 
Tem a função de adicionar a quantidade de um produto no estoque (apenas para produtos que já existam)

3 - registrar_saida: 
Tem a função de retirar a quantidade de um produto no estoque (apenas para produtos que já existam)

4 - consultar_estoque:
Tem a função de consultar o estoque visualizando o produto e sua quantidade (se não existir produto não vai aparecer nada)

5 - alerta_estoque_baixo:
Tem a função de alertar quando um produto está abaixo do estoque definido pelo usuario.

6 - menu:
Tem a função de um menu que vai conter todas as 5 opções que foram descritas acima além do sair (0). 

7 - main:
Roda o código no Visual studio.

# Como Rodar 
1 - instale o vs code 

2 - baixe os 7 arquivos da qui do git hub (que não seja o README)

3 - coloque todos esses aquivos no vs code já instalado
